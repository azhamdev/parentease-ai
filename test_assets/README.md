# Test Assets

These PDFs are synthetic test data that mimic filled Buku KIA/KMS pages. They
are not real patient data.

Files:

- `sample_kia_growth_filled.pdf`: single-page growth + immunization note sample.
- `sample_buku_kia_filled_pages.pdf`: multi-page Buku KIA sample based on pages
  62, 63, 64, 65, 67, 73, and 74.

Use it to test:

- async PDF upload jobs,
- OCR/growth extraction,
- `growthrecord` persistence,
- vaccine record extraction from dated immunization notes.
